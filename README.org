This package reduces the width of displayed content.  It is similar to olivetti-mode and perfect-margin-mode, but lighter (to my eyes).  It runs as a global mode, but can be enabled/disabled on a per-file basis.

If the total-width of a window is larger than ~temper-width-width~, its margins are modified to make body-width≈temper-width-width.

The function ~temper-width~ is added to ~window-size-change-functions~.

Set ~temper-width-enable-on-prog-derived~ to ~t~ to temper all windows derived from ~prog-mode.~

To temper all buffers with a certain major-mode, add it to ~temper-width-allowed-modes~.

To force-enable temper-width for a certain buffer, set the variable ~temper-width-force-enable~ to ~t~.  Similarly, to force disable, set ~temper-width-force-disable~ to ~t~.

Helper functions ~temper-width-force-enable-locally~ and  ~temper-width-force-disable-locally~ are provided.  Call them with a prefix argument to disable their effect.

To /only/ enable temper-width on specific buffers and nowhere else, enable `temper-width-blind-global-mode', then call `temper-width-force-enable-locally' (or set `temper-width-force-enable' to `t').

`temper-width-global-mode' and `temper-width-blind-global-mode' are mutually exclusive.

Sample config:
#+BEGIN_SRC elisp
  (setq-default temper-width-width 120)
  (setq temper-width-enable-on-prog-derived t)
  (setq temper-width-allowed-modes '( text-mode dired-mode
                                      magit-mode Info-mode
                                      conf-colon-mode helpful-mode
                                      shortdoc-mode))
  (add-to-list 'temper-width-allowed-modes 'org-mode)
  (temper-width-global-mode t)
#+END_SRC
