This package reduces the width of the displayed content in a buffer.  It is similar to olivetti-mode and perfect-margin-mode, but lighter and lacks features.

 It calculates the width of a windows, and if it is larger than squish-content-width, adjusts the margins using set-window-margin for that specific window.  It associates itself with hooks that fire when a window is introduced, or when its dimensions are changed.
